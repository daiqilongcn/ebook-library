# ebook-library

个人收藏的电子书库，按「世界认知树」的知识体系进行分类整理，涵盖从自然科学到人文社会的各个领域，目前共收藏 100+ 册图书（epub / pdf / mobi / azw3 等多种格式）。

## 知识体系

书库分类基于 `世界认知树.md`，以知识主线划分：

| 主线 | 涵盖部分 |
|------|----------|
| 真理 | 认识论、数学/统计、科学方法（第1~3部分） |
| 实在（自然） | 物理/化学/地球、生命/演化（第4~6部分） |
| 复杂系统 | 系统、信息与复杂性（第7部分） |
| 人 | 心智（第8部分）、群体（第9~11部分）、文明（第12部分） |
| 技术 | 能源/工业/计算/AI（第13部分） |
| 价值 | 哲学、宗教、文学、艺术与审美（第14~15部分） |

部分书目为「牛津通识读本（Very Short Introductions）」系列，是快速了解各学科的第一站。

## 文件格式

- `.epub` — 主力格式，支持电子书阅读器/手机端阅读
- `.pdf` — 电子书、菜谱等排版类文档
- `.mobi` / `.azw3` — Kindle 格式
- `.txt` — 文案库等纯文本收藏

## 其他说明

- `ePub编辑器/` 为自制 EPUB 编辑工具（含数据库、使用说明 `readme.pdf` 及安装包 `ePub编辑器/安装包/ePub编辑器 V3.2.1【2025-06-20】.zip`），方便自行整理书库
